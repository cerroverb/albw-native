A Link Between Worlds - native PC port (Windows)
================================================

You need your own decrypted dump of the European release. No game data is included.
The file:

  0487 - Legend of Zelda, The - A Link Between Worlds (Europe) (En,Fr,De,Es,It) Decrypted.3ds
  748,580,864 bytes, SHA-1 4d2da91fa0edef9eef07e471527461396cc3faf2

The name does not matter (a renamed copy works); the contents must match. The USA and Japanese
releases do not work.

1. Unzip this folder anywhere (keep all files together).
2. Put your .3ds file in the "roms" folder inside it (or next to ALBW.exe).
3. Double-click ALBW.exe. If no .3ds file is found there, it asks for one the first time; the
   choice is remembered (in %USERPROFILE%\.config\albw-port\rom_path - delete that file to choose again).

Saves, save states and settings live in %USERPROFILE%\.local\share\albw-port\
The game's log is albw.log, next to ALBW.exe - attach it when reporting a problem.

Controls: keyboard or any controller (Xbox, PlayStation, Switch Pro ...).
Esc opens the menu (controls, screen layout, save states, reset).

If the window stays black or the game says OpenGL is missing: your PC has no OpenGL 3.3
driver (common in virtual machines or over Remote Desktop). Install your graphics driver,
or start ALBW.exe with the environment variable ALBW_SOFTWARE_GL=1 to use the bundled
software renderer (mesa folder; on a PC without a graphics card it is very slow, it is only meant to get the game to start).

Texture packs (higher-resolution textures, e.g. Henriko Magnifico's "ALBW 4K"):
  Unzip the pack and put its folder in a folder named "texture-pack" next to ALBW.exe, so that
  texture-pack\...\pack.json exists (the "user\load\textures\00040000000EC300" folder of the pack
  zip is found by itself). Packs in the Citra / Azahar format work; the pack must use the new hash
  ("use_new_hash": true in its pack.json; this one does). albw.log says "texpack: replacement textures
  from ..." when it is used. The 4K pack uses a lot of memory: try its 1080p version first.

Trouble starting?
  - Unzipped from a download and SDL3.dll will not load: right-click the .zip > Properties >
    tick "Unblock" > OK, then unzip again.
  - Slow or stuck start: the game may be on the software renderer (it says so in a message box).
    Install / update your graphics driver.
  - To force a mode, make a shortcut to ALBW.exe and add  --software-gl  (software renderer),
    --system-gl (graphics driver) or --console (show the log in a window) after its path.
  - If antivirus software complains that ALBW.exe starts a copy of itself: that is how the game
    reserves its memory reliably. Set the environment variable ALBW_NO_LAUNCHER=1 to skip it.
  - When something goes wrong: press Esc in the game > Help > "Copy log to clipboard", then paste
    it (Ctrl+V) into a new issue at github.com/spacestate1/albw-native/issues. If the game stops with
    an error, the log is already on the clipboard. The file is albw.log (see above).
  - If the window shows "Not Responding" and stays black: wait 2 minutes, then send albw.log. It lists
    what every part of the game was doing ("albw: watchdog" lines).
